# Security Policy

TSIC must never contain production secrets, private keys, customer data, PHI, or regulated operational records.

Security baseline:
- OWASP API Security Top 10.
- OWASP ASVS 5.0 where applicable.
- Least privilege and deny-by-default integration.
- Explicit tenant and authorization propagation.
- Supply-chain hygiene.
- Immutable certification evidence references.

Suspected vulnerabilities must be reported privately through the repository's configured security channel.
