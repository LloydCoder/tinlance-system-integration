# Governance

TSIC owns ecosystem-level integration contracts, registry metadata, compatibility policy, conformance requirements, verification tooling, and certification evidence.

It does not own domain runtime execution.

Agent Platform remains authoritative for governed agent execution, identity/authorization, policy, runtime, tools/MCP, sandbox, secrets, budgets, evidence, audit, and observability.

Agent OS remains authoritative for workspace/environment/lifecycle/orchestration above the Platform.

Domain systems retain authority within their declared domains.

If two systems appear to own the same capability, the conflict must be resolved before the capability is considered integrated.
