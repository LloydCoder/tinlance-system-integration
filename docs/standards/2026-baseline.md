# 2026 Standards Baseline

Phase 0 adopts broadly used standards by purpose:
- OpenAPI 3.1 for HTTP API descriptions.
- AsyncAPI 3.x for message-driven API descriptions.
- CloudEvents 1.0.x for portable event metadata.
- JSON Schema 2020-12 for JSON validation.
- OpenTelemetry semantic conventions for telemetry.
- Semantic Versioning 2.0.0 for release/contract versioning.
- OWASP API Security Top 10 and ASVS 5.0 for applicable security controls.

Standards are adopted by purpose; TSIC does not force a protocol where it is inappropriate.
