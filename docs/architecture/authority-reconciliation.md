# Authority Reconciliation

The ecosystem follows single-authority ownership. Agent Platform remains authoritative for agent identity, authorization, policy, runtime, tools/MCP execution, sandbox, secrets, budgets, evidence, audit and execution observability. Agent OS owns workspace/environment and lifecycle/orchestration. TSIC owns integration contracts, compatibility and conformance evidence only. Domain systems retain domain authority.

No adapter may create a parallel runtime, authorization plane, secret store, or policy authority.
