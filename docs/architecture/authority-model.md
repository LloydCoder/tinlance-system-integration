# Authority Model

TSIC owns ecosystem-level integration and conformance concerns.

Agent Platform owns governed agent execution and its established platform responsibilities.

Agent OS owns workspace/environment/lifecycle/orchestration above the Platform.

TADS/SDEA, ReconOS, FadeReach, FDSE, FDE, Transformation, World Intelligence, FAS, Hezqara, BugFlow, and other systems retain authority in their declared domains.

If two systems appear to own one capability, integration is blocked until ownership is resolved.
